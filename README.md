# Propósito

El propósito de este repositorio es documentar la aplicación del algoritmo *Random Forest* en un proceso de aprendizaje automático supervisado.
Toma los datos de los sensores del repositorio [Porvenir](https://github.com/aldodds/Porvenir) para predecir el comportamiento de las variables monitoreadas en campo a partir de registros históricos.

# Bibliotecas utilizadas

Instaladas desde la terminal usando `VSCode`.
- pandas
- requests
- matplotlib
- python-dateutil

```bash
pip install pandas requests matplotlib python-dateutil
```
